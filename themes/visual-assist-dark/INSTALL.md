# Visual Assist Dark 导入和更新指南

适用于 Visual Studio 2022 / 2026。通过 VS 的“导入和导出设置”向导应用本目录的 `.vssettings` 文件。

**如果你已经使用内置的“深色 / Dark”主题，可以直接开始下面的导入流程。** 备份是可选的，也可以在导入向导中完成，无需提前单独导出。

## 选择要导入的文件

| 使用情况 | 选择的文件 |
| --- | --- |
| 使用 VS 原生 C++ 着色，没有启用 VA 增强着色 | [Visual-Assist-Dark.vssettings](Visual-Assist-Dark.vssettings) |
| 仍在使用 Visual Assist 的增强语法着色 | [Visual-Assist-Dark-with-VA.vssettings](Visual-Assist-Dark-with-VA.vssettings) |

通常选择第一份，两个版本任选其一。

本机的主题目录是：

```text
D:\项目\dev\cpp\cp-algorithm\themes\visual-assist-dark
```

如果工作区以后移动到其他位置，使用新位置下的同名文件。

## 导入流程

### 1. 确认当前使用深色主题

已经是内置深色主题时，跳过本步。

否则按 **Ctrl+Q**，搜索“颜色主题”或“Color theme”，进入对应设置并选择 **深色 / Dark**。先切换主题，再导入配色。[微软主题设置说明](https://learn.microsoft.com/en-us/visualstudio/ide/how-to-change-fonts-and-colors-in-visual-studio?view=visualstudio)

### 2. 打开导入向导

在 VS 顶部菜单选择：

**工具 → 导入和导出设置**

在向导首页选择 **导入选定的环境设置**，点击 **下一步**。

### 3. 选择是否保存当前设置

在“保存当前设置”页面，按自己的需要选择：

- 想保留当前配色以便恢复：选择 **是，保存我的当前设置**，指定保存位置和文件名，例如 `VS-导入VA配色前.vssettings`。
- 已经备份过，或者不需要备份：选择 **否，仅导入新设置，覆盖我的当前设置**。

然后点击 **下一步**。本次导入会应用文件中的配色和指定字重；主题文件没有设置字体名称、字号、快捷键或项目配置。

### 4. 选择主题文件

在 **选择要导入的设置集合** 页面，点击左下角的 **浏览**。

在文件选择窗口的“文件名”栏粘贴完整路径：

```text
D:\项目\dev\cpp\cp-algorithm\themes\visual-assist-dark\Visual-Assist-Dark.vssettings
```

使用 VA 兼容版时，将文件名改为：

```text
Visual-Assist-Dark-with-VA.vssettings
```

点击 **打开**，回到向导后确认选中了对应文件，再点击底部的 **下一步**。

**这一页看不到“环境”是正常的。** 如果左侧显示“默认设置”“我的设置”“最近的文件”，你仍在选择设置文件。“环境 → 字体和颜色”在下一页。

### 5. 选择要导入的设置类别

在下一页的设置树中展开 **环境**，确认勾选 **字体和颜色**。

本主题文件只包含这一类设置。点击 **完成**。

### 6. 查看导入结果

在结果页确认没有导入失败提示，再点击 **关闭**。如果出现错误，保留具体提示，便于判断问题。

以上向导入口、文件选择及类别选择流程可参照[微软导入与导出设置说明](https://learn.microsoft.com/en-us/visualstudio/ide/personalizing-the-visual-studio-ide?view=visualstudio)。

### 7. 打开 C++ 文件检查效果

打开项目中的 `main.cpp`，或者按 **Ctrl+O** 打开本目录的 [semantic-gallery.cpp](semantic-gallery.cpp)，等待 IntelliSense 解析完成。

原生版当前预期效果如下：

| 内容 | 预期效果 |
| --- | --- |
| 类、结构体、类型别名、类模板 | 金色 |
| 函数名称 | 橙色 |
| 局部变量、函数形参 | 卡其色加粗 |
| 全局变量、成员字段 | 卡其色常规字重 |
| `cin`、`cout` 等全局对象 | 常规字重 |
| `<<`、`>>`、`[]` 等普通或重载运算符 | 灰色 |
| 宏 | 紫色 |
| 注释 | 绿色 |
| 字符串 | 柔和的鲑色 |

可对照 [配色预览](preview.png)。预览为示意图；实际符号分类由 VS 的 C++ 语言服务决定。

## 已经导入旧版时如何更新

主题文件更新后，需要重新导入才能应用到 VS。

1. 打开 **工具 → 导入和导出设置**。
2. 选择 **导入选定的环境设置**。
3. 按需备份当前设置。
4. 浏览并选择本目录里更新后的同名 `.vssettings` 文件。
5. 勾选 **环境 → 字体和颜色**，点击 **完成**。
6. 回到 C++ 编辑器检查变化。

已经使用内置深色主题时，直接重新导入即可。

## 恢复原来的配色

如果导入前保存了备份，重新打开导入向导，选择备份的 `.vssettings` 文件，在类别页勾选 **环境 → 字体和颜色** 并完成导入。

恢复其他设置时，再选择相应类别。如果备份时使用的是另一种整体主题，也可重新选择当时使用的主题。

没有备份时，可在“字体和颜色”设置中使用 **使用默认值** 恢复相应类别的默认设置；这也会影响该类别中其他手动调整过的项目。

## 常见情况

| 情况 | 处理方式 |
| --- | --- |
| 文件选择页看不到“环境” | 先选中主题文件并点击“下一步”；类别在下一页。 |
| 主题下拉框仍然显示“深色” | 这是正常的。本文件应用编辑器配色，不会增加新的主题名称。 |
| 导入后暂时看不到变化 | 关闭并重新打开 C++ 文件；仍未更新时，保存工作后重启 VS。 |
| 函数、变量仍然大多是灰色 | 检查文件是否处于 C++ 项目上下文，及 C/C++ 的 IntelliSense、增强颜色设置是否启用。 |
| 曾为了 VA 关闭原生 IntelliSense | 改用原生版时，需要重新启用原生 IntelliSense。 |
| 更新后 `<<`、`>>` 或 `[]` 仍为橙色 | 确认重新导入的是本目录更新后的文件，而不是此前另存的旧副本；若启用了 VA 增强着色，也需考虑 VA 自身的颜色设置。 |
| 使用 VA 兼容版后字重与原生版不同 | 兼容版把符号字重交给 VA；具体选项见 [粗体与斜体说明](README.md#粗体与斜体)。 |
| 系统库函数没有斜体 | 这是当前原生版的预期效果：系统库函数保持常规字形，详见 [粗体与斜体说明](README.md#粗体与斜体)。 |

更多颜色、版本变化及实现范围见 [主题说明](README.md)。
